# Baseline formal comparison

The recovered **baseline** and the model decoded from the actual regenerated binary passed a direct all-state transition comparison and both bounded normal-operation transaction comparisons. A separate baseline-to-preserved-mapped-netlist transition comparison also passed. No RTL repair or replacement synthesis was applied.

| Baseline → preserved `mapped_clean.json` | PASS | All 135 next-state bits and all three external outputs for every paired current state and every common input valuation |

## Exact meaning and assumptions

All four RAM primitives on each side were expanded using the same hash-pinned iCE40 behavioral library. Their fixed initialization contents were retained and optimized as constants; no memory or primitive blackboxes remain. Each prepared model has 71 one-bit logic registers initialized to zero and four 16-bit RAM read-output registers with unspecified initial values: 135 state bits total. Every state element was audited as positive-edge SCK. One abstract formal step represents one rising SCK edge. Inputs and state are binary; this does not model analog timing, metastability, propagation delays, or clock glitches.

The transition proof cuts every DFF at Q and compares every corresponding D input and all three outputs. The 135-bit state map is explicit and bijective; no internal node is accepted as an unproved blackbox. The direct decoded correspondence follows physical BEL coordinates through `physical_decoded_correspondence_v3.json`; its naming only proposes the relation, while SAT proves the resulting equations. All input valuations and paired current-state valuations are allowed. Known initial states match, and the two sets of possible unspecified initial RAM-read states correspond under that bijection. Thus the result supports an inductive relational equivalence for arbitrarily long input sequences from corresponding initial states. It **does not** assert equal power-up traces for two independently chosen unknown RAM-read states.

That distinction is addressed separately for the normal-operation transaction: the bounded proofs instantiate independent RAM read-output states on both sides and impose no cross-design state assumptions. One shared arbitrary stable 32-bit payload drives the exact original schedule: reset at cycle 0, release at 1, load at 2–33, launch at 34, seven extra clocks at 35–41, and read at 42–73. MISO, BUSY, and ICE_LED are compared at states 1–74. At state 74, the 31 collected samples plus the current MISO are compared as the entire 32-bit readback. Both modes passed through solver state 75. The controls are generated by the harness, so this bounded result is limited to that schedule. It proves preservation of baseline behavior, not correctness against an independently specified algorithm or removal of the baseline's readiness limitation.

Audit found one literal unknown branch in the baseline equations and one in the decoded equations. The stronger transition proofs replace those occurrences with **independent arbitrary defined** values, enable undefined-value modeling, and still pass. The final miter audit confirms no residual x/z connection literals, comparator widths `[1,1,1,135]`, one always-enabled assertion, and zero assumption cells. Use the `transition_*_undef_independent` results as the final transition evidence.

## Preserved unsuccessful attempts

1. `eqy_01`: failed to combine because unused generic blackbox library modules remained on the mapped side. No proof result.
2. `eqy_02`: full-model preparation succeeded after unused-library cleanup and instantiated-blackbox rejection, but the EQY partition subprocess segfaulted with exit 139. EQY returned 1. No equivalence conclusion was drawn.
3. `tool_help_01`: requested useful Yosys help and an unsupported `version` command. Help output is retained; subsequent `yosys -V` succeeded.
4. `audit_prepare`: an incorrect script path failed before reading a design. `audit_prepare_02` used the correct path and succeeded.
5. `builtin_equiv`: generic sequential equivalence processing exceeded the 240-second limit. Partial results are not claimed as a proof.
6. `transition_decoded_attempt01_failure.json`: correspondence preparation stopped on a physical indexed alias absent from baseline names. No SAT run occurred.
7. `transition_decoded_attempt02_failure.json`: preparation stopped on the physical MISO output-buffer alias. No SAT run occurred. Both failing script revisions are retained. Final resolution passes through preserved mapped aliases and normalizes an output-buffer alias to its mapped output port; the final equations were then proved.
8. `direct_transaction_mode1_cover`: reached the cover at step 74, but serializing a full internal-wire VCD exceeded the 120-second timeout. The partial trace is retained and not treated as a completed PASS run. A subsequent compact export of the same model completed and passed in both modes.

The earlier baseline-to-mapped leg alone is not RTL-to-bitstream equivalence. The direct decoded leg specifically compares against the model recovered from this run's actual regenerated binary, subject to decoder, adapter, and primitive-model trust. There is no board programming, board pin validation, hardware timing guarantee, or claim that the regenerated binary is bit-for-bit identical to the original binary.
